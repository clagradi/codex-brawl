# Balance report

Generated by `node tools/balance.mjs` (do not edit by hand). CPU against CPU, 12 seeded matches for every ordered pair of fighters (300 finished matches, seeds 1 to 300), difficulty normal, 2 rounds to win, 99 seconds per round, arenas rotating.

Read it with care: the players are the CPU brain, which plays every fighter by the same rules, so this measures how well the brain uses each move set and where the numbers lean, not what a human can do. One standard error is about 14 points for a matrix cell (12 matches) and about 5 points for a fighter row (120 matches), so treat a gap smaller than twice that as noise and re-run with another `--seed0` before acting on it.
